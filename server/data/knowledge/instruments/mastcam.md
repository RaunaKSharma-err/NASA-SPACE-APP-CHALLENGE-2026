# Mastcam and Mastcam-Z

## Mastcam (Curiosity / MSL)
Mastcam is a pair of cameras on NASA’s Curiosity rover that provide color images, video, and 3D views of the Martian terrain and atmosphere.

- **Platform:** Curiosity rover, Gale Crater
- **Data type:** Multispectral/context imaging, panoramas, atmospheric observations
- **Uses:** Document geology, stratigraphy, rover surroundings, and targets

## Mastcam-Z (Perseverance / Mars 2020)
Mastcam-Z is the main mast-mounted camera system on NASA’s Perseverance rover with zoom capability and stereo imaging.

- **Platform:** Perseverance rover, Jezero Crater
- **Data type:** Zoomable color/stereo imaging, panoramas, video
- **Uses:** Geologic context, navigation support, target selection, documentation

## Scientific Value
- Provides visual context essential for interpreting other measurements.
- Helps identify rock textures, layers, and sedimentary structures.
- Supports rover operations and science planning.

## Limitations
- Imaging shows appearance and morphology, not complete chemistry/mineralogy alone.
- Observations are local to rover locations and viewing conditions.

## MARSYN Status
Mastcam/Mastcam-Z imagery is not integrated as a scientific layer in MARSYN. Perseverance imagery is from Jezero Crater and is not geographically applicable to MARSYN’s current Gale Crater focus.
